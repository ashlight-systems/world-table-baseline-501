# Preserved World Table baseline images

This folder contains the rebuilt local image copies for the original World Table
501-recipe baseline.

The image binaries were re-encoded by Ashlight Systems from the URLs declared in the
frozen source dataset. Per-image author, licence, original source URL and SHA-256 are
recorded in `../ashlight/manifest.json`.

These files do not all share one image licence. Check the manifest entry for the
specific image before reuse.
