# World Table 501 image preservation mirror

This directory records the Ashlight Systems preservation process for the original
501-recipe World Table baseline.

## What happened

Ashlight used the frozen 501-recipe JSON as a bounded manifest. Every non-null
`photo.url` was retrieved by the local World Table Image Mirror tool.

Each downloaded image was:

1. opened as image data;
2. orientation-normalised;
3. re-encoded into a fresh JPEG/PNG/WebP file;
4. written under `../images/` using the stable source filename;
5. hashed with SHA-256; and
6. recorded in `manifest.json` with its recipe slug, original source URL, author,
   licence, dimensions and byte size.

The temporary raw downloads were deleted after successful re-encoding.

## Important distinction

Re-encoding removes ordinary embedded metadata/container baggage from the working copy.
It does not change the legal attribution requirements of the original photograph.

The author/licence/source evidence is deliberately retained outside the image binary in
`manifest.json`.

## Files expected here

- `unitools-recipes-v1-world-table-501-baseline.json`
- `manifest.json`
- `retrieval-report.txt`

The first file is the frozen source snapshot. The other two are generated by the local
mirror run and should be uploaded unchanged.

## Do not

- Do not overwrite the upstream `unitools-recipes-v1.json`.
- Do not rewrite upstream Git history.
- Do not apply one blanket photo licence to all 406 images.
- Do not delete original source URLs from the manifest merely because Ashlight later
  hosts the working copies.
