# Ashlight Systems preservation layer

This repository is a fork of the upstream UniTools recipe dataset and preserves the
original World Table 501-recipe baseline used by Ashlight Systems.

The upstream files and history are retained. Ashlight adds a preservation layer so
The World Table does not depend operationally on a third-party image host remaining
available.

## Ashlight additions

- `images/` — rebuilt local copies of the 406 recipe images referenced by the frozen
  501-recipe baseline.
- `ashlight/unitools-recipes-v1-world-table-501-baseline.json` — exact frozen dataset
  snapshot used by The World Table.
- `ashlight/manifest.json` — per-image preservation receipt generated by the local
  mirror tool: recipe slug, source URL, author, licence, filename, SHA-256, dimensions
  and byte size.
- `ashlight/retrieval-report.txt` — retrieval summary for the preservation run.
- `ashlight/README.md` — process and provenance notes.

## Rights and attribution

Ashlight does **not** replace or flatten the rights recorded by the source dataset.

Recipe and photo attribution/licence information remains per record/per image. The
rebuilt image files are preservation copies; their corresponding author, licence and
source URL are retained in `ashlight/manifest.json`.

The original UniTools source remains credited as the upstream dataset source. Ashlight
Systems is the operator of this preservation mirror and the World Table publication
layer.

## Operational intent

The World Table may later serve these preserved images from Ashlight-controlled
infrastructure while retaining the original source attribution and licence evidence.
No third-party image host needs to remain a live runtime dependency.
